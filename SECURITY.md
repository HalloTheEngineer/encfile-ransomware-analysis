# Security policy

This repository contains defensive analysis and detection content. It does not
contain a live malware sample or victim data.

## Reporting a problem

If you find a safety, privacy, or detection-integrity issue, use the repository
host's private security-reporting channel when available. Do not open a public
issue containing:

- live malware or a download link;
- victim files or ciphertext;
- credentials, tokens, or private keys;
- personal or customer data;
- incident infrastructure details.

For ordinary corrections to documentation or detection logic, a public issue
is fine.

## Scope

Use this material only for authorized defense, incident response, research, and
detection engineering. Do not use it to deploy, extort, or target systems.
